# Bride&Groom Instagram post generator

Operators answer a questionnaire (`/new-post`); Claude assembles posts from Figma template components and places them on the `Generated` page. `/sync-templates` rebuilds the template manifest; `/edit-run` changes an existing run.

## Hard rules
- **Any account.** No personal tokens, IDs or paths in the repo. Figma goes through the remote Figma MCP (`.mcp.json` at the repository root, per-user OAuth). The only file-specific value is `config.json → fileKey`.
- **Resolve templates at runtime.** Use `templates/manifest.json` (component keys + slot paths); never hardcode node IDs. Choice lists always come from the manifest.
- **Never modify `Templates` or `Design system`** without explicit confirmation from the operator in this session. Frames whose name contains `(CLAUDE - IGNORE)` are never read as templates or modified.
- **Brand safety.** Never change font sizes, colors or layout of a template to make content fit. If text overflows, report the slide + slot and ask the operator to shorten it or pick another layout.
- **Output** goes only to `Generated`: one Section per run with a summary card + slide instances (overrides only, never detached). Uploaded photos are staged on `Media`.
- **No placeholders shipped.** A slot may keep its default text only when the operator explicitly keeps it; record that in the run.

## Figma MCP rules
- `create_session` once per run with the fileKey; pass `sessionId` to every Figma call.
- Load `skill://figma/figma-use/SKILL.md` via `get_figma_skill` before the first `use_figma` call; pass `skillNames: "resource:figma-use"`.
- Switch pages only with `await figma.setCurrentPageAsync(page)`, once per call. Never use `loadAllPagesAsync`, `setPluginData`, `createImageAsync`. Code ≤ 50k chars per call.
- `use_figma` returns are capped at 48 KB — page large reads (see `/sync-templates`).
- Figma soft line breaks are U+2028, which breaks the MCP transport: normalize to `\n` before returning text (see `safe()` in `figma/scan-templates.js`). Build regexes for these from char codes, not `\u` escapes.
- Before writing text, `await figma.loadFontAsync` for every font in the node (`getRangeAllFontNames` handles `figma.mixed`).
- On a permission/seat error, stop and tell the operator exactly which access is missing (check with `whoami`).
- Arrays returned by the Plugin API (e.g. `getStyledTextSegments`) are frozen: index them, never `pop()`/`splice()`.
- Each lookup returns a new wrapper object for the same node: compare nodes by `id`, never with `===` or a `Set` of nodes.
- Templates may stack several placeholder images in one layer and repeat the slot's photo elsewhere (story backgrounds). `build-run.js` replaces all of them, and `verify-run.js` checks that no template photo is left visible.
- The screenshot check is mandatory even when `verify-run.js` passes: text running past a card drawn as a separate shape is only visible there.

## Files
- `config.json` — fileKey, page names, scan settings, export sizes, layout gaps, run order, UI language.
- `templates/manifest.json` — generated by `/sync-templates`; never edit by hand. Schema: `templates/manifest.schema.json`.
- `templates/previews/` — one ~270 px PNG per template variant (`<component key>.png`) + `index.json` (the `look` each was exported from). Kept in step by `/sync-templates` with `scripts/previews.mjs`; shown to operators as contact sheets (`scripts/contact-sheet.mjs`).
- `figma/*.js` — reference scripts inlined into `use_figma` calls (replace the `const ARGS =` line).
- `runs/<runId>.json` — local audit log per run. `runs/.cache/` (git-ignored) holds a session's downloads, contact sheets and screenshots.
- `scripts/fetch-image.sh` / `scripts/upload-asset.sh` — the only way images are downloaded or uploaded (no bare `curl`): they are pre-approved, so keep them narrow.
