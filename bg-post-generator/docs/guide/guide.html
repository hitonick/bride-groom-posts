Operator Guide: creating Instagram posts with Claude Code and Figma

Version 2.0 · October 2026
For: anyone on the team who creates Instagram content
No design or coding skills required

1. How it works

You describe the post in a conversation with Claude Code. Claude builds it in Figma from the approved Bride&Groom templates and places the result on the Generated page. You never need to design anything in Figma; you only open it to review and export.

The workflow at a glance

  1. Start: in Claude Code, type /new-post.
  2. Answer the questions. Claude asks one question at a time: format, content type, color, slide structure, text, images, caption.
  3. Add images by dragging files into the Claude Code window or giving a file or folder path.
  4. Review. Claude shows a summary table of everything it will build. Confirm it, or jump back to any step.
  5. Claude builds and checks the post in Figma: correct template, your text, your photos, no leftover placeholder text, no text overflow.
  6. Open the link Claude gives you, check the slides, and export the PNG files for Instagram.

What you get in Figma

Each request (a run) becomes one section on the Generated page, named like BG-20261023-1430-anna · Carousel · Wedding film tips. Inside it:

  • a summary card: who requested the post, when, which templates were used, all your answers word for word, the images used, the caption and hashtags, and any warnings;
  • the slides, in order, each with a label underneath (01 Cover, 02 Photo + Title, ...) and export settings already applied.

What Claude will never do

  • Change fonts, font sizes, colors or layout to make text fit. If text is too long, Claude tells you and asks you to shorten it or pick another layout.
  • Ship template placeholder text (for example "Noah Kokensparger" or lorem ipsum), unless you explicitly choose to keep it.
  • Modify the Templates or Design system pages without asking you first in that session.

2. One-time setup

Setup takes about 10 minutes and is the same for every person and every Claude account.

What you need

ItemDetails
Claude account with Claude CodeA personal plan (Pro or Max) or a company plan (Team or Enterprise) that includes Claude Code.
Claude CodeThe Claude desktop app (Code tab) or the Claude Code terminal app. Both work the same way.
Figma accountAny Figma account with edit access to the Bride&Groom templates file. View-only access is not enough, because Claude writes to the Generated and Media pages.
The project folderbride-groom-posts (with bg-post-generator inside it), shared by your team (Git repository or zip archive).

Step 1. Install Claude Code

Desktop app: download the Claude app from claude.ai/download, sign in, and open the Code tab.

Terminal (macOS / Linux):

curl -fsSL https://claude.ai/install.sh | bash

For Windows and other options, see docs.claude.com → Claude Code → Setup.

Step 2. Get the project folder

Clone the team repository, or unzip the archive you received, to a convenient place, for example your Desktop:

git clone <team-repository-url> bride-groom-posts

Step 3. Open the folder in Claude Code

Open the top folder, bride-groom-posts, not the bg-post-generator folder inside it: /new-post and the Figma connection only load from the top folder.

Desktop app: in the Code tab, choose the bride-groom-posts folder as the working folder.
Terminal:

cd bride-groom-posts
claude

If Claude Code asks whether to trust the folder, or whether to use the project's figma server (found in .mcp.json at the repository root), say yes.

Step 4. Connect your Figma account

The project uses the official Figma server (https://mcp.figma.com/mcp). You sign in with your own Figma account. No passwords or tokens are stored in the project folder.

  • Terminal and desktop app: type /mcp, select figma, then Authenticate. A browser window opens. Sign in to Figma and click Allow access.
  • Desktop app, alternative: connect the Figma connector in the Claude settings (Settings → Connectors). If your account already has it connected, there is nothing to do: Claude uses whichever Figma connection is available.
  • Cloud sessions (claude.ai/code, opened on the GitHub repository): use the connector. Add Figma at claude.ai/customize/connectors, sign in with your Figma account, then start a new session. The /mcp sign-in does not work there.
Permission prompts. The project pre-approves the Figma tools and its own helper scripts, so Claude should not ask before every Figma step. If your Figma tools appear under an unusual name, Claude asks once per tool: choose Always allow. In cloud sessions you can also choose Auto in the mode menu next to the prompt box, if your organization allows it.

Step 5. Check access to the file, then start

Open the Figma file link in your browser. If you see "View only" or cannot edit, ask the file owner to share it with you as can edit. Then, in Claude Code, type:

/new-post

Before the first question, Claude checks everything automatically: the Figma connection, your identity, the file, the required pages and the template list. If something is missing, it tells you exactly what to fix.

3. Creating a post with /new-post

Type /new-post. Claude asks how you want to work:

  • Detailed: 9 short questions, and you choose everything yourself (this section).
  • Quick: describe the post and add photos; Claude chooses the layout, color and text, and you approve one summary (section 4).

You can skip that question with /new-post detailed or /new-post quick.

See before you choose. When you pick a color or a layout, Claude first shows one picture with the options side by side, numbered and labelled like the answers. For a carousel it shows the slide sequence as a strip, and it shows the strip again before building.

In Detailed mode, Claude asks one question per step and shows a counter such as 3/9. For multiple-choice questions, pick an option with the arrow keys and Enter (or click it). A list shows at most four options. When there are more, the last one is More…, and the question names the rest. You can also choose Other and type any option by name (for example a color). For free-text questions, just type and press Enter. Steps that don't apply are skipped, so the counter may jump (for example 4/9 → 6/9 for a review, which is always typed and skips the content-mode question).

At any step you can type back to return to the previous question, or cancel to stop without building anything.
StepWhat Claude asksNotes
1. FormatFeed post (single), Carousel, Story, or Story setFeed posts are 4:5 portrait. Stories are 9:16.
2. Content typeReview, Cover, Carousel article, Poll / Question / Opinion story, ...Only types that exist for the chosen format are offered.
3. ColorBrand palette, with how many layouts exist in each colorA slide whose layout lacks your color uses the lighter/darker version (Pink ↔ Light Pink), then a neutral (Light Color, Light, Dark). Claude tells you which slides, and never switches to a different hue without asking.
4. StructureSingle post or story: the layout. Carousel / story set: number of slides, then the layout of each slideCarousels have 2–20 slides (Instagram's limit). Choose auto-compose (Claude picks a varied sequence: cover → content → outro) or manual.
5. Content mode"I'll type the text" or "Draft it from a brief"For a draft, you give the topic, key message, audience, tone and call to action. You can edit the draft before anything is built. Reviews are always typed: Claude never invents quotes, names or ratings.
6. TextEach text field, one by one, with a character budget. After a draft, only the fields the draft did not fill (for example "keep the template's Swipe button?")See "Typing text" below. Page numbers and brand tags are filled in automatically.
7. ImagesOne image for each photo or avatar slot, plus an optional background on some storiesSee section 6.
8. CaptionInstagram caption and hashtags (optional)Write your own, or ask Claude to draft them. Instagram allows at most 5 hashtags per post.
9. ReviewA compact table of everything that will be builtConfirm to build, or name the step you want to change.

Typing text

Each question shows how much text fits, for example title (≈30 chars, 2 lines; the last part is italic). For quotes and longer texts it also says how much fills the design: a much shorter text leaves an empty gap.

You typeWhat happens
Five things your | film needsThe part after | is set in the italic accent style. Without |, Claude picks the last words that fit the accent line and shows you the split.
keepKeeps the template's own text for this field (useful for story headlines such as "Poll Time!"). Claude offers this as a choice where it makes sense.
hideHides an optional field instead of leaving placeholder text.

Bullets in list fields are added by the template, so don't type 1. or •. If a text is longer than the budget, Claude asks you to shorten it, keep it and check the real fit when building, or pick another layout.

Reviews: what to prepare

For a review post, have these ready: the review text (quote), the author's name, their Instagram handle (if the layout shows one), the source (Google or Facebook), the star rating, and the author's photo (if the layout has an avatar).

4. Quick mode: /new-post quick

Write what the post is about in one message, add the photos, and Claude does the rest:

you:    /new-post quick
Claude: Tell me what the post is about: topic, key message, call to action,
        and if you like the format and a color or mood. Then add the photos.
you:    Carousel about 3 details couples forget for a garden ceremony:
        shade, sound and a rain plan. CTA: save this for your planning.
        Warm colors. ~/Desktop/garden-shoot/
Claude: [strip of the 5 slides] + a table: layout, color, every text,
        which photo goes where, caption, warnings
        › Build it · Change something · Switch to detailed · Cancel
  • Claude uses the same rules as Detailed mode: only approved templates, the closest color when a layout lacks yours, text within each field's limit, and the photos that need the least cropping.
  • Change something: say it in plain words ("slide 3 title shorter", "use the other photo on the cover", "make it blue").
  • Switch to detailed keeps what was decided and walks you through the 9 questions.
  • Claude never invents reviews, names, ratings, numbers or prices. For a review post, paste the real review. Text you put in "quotes" is used exactly as written, and Claude asks before shortening it.
  • Photos that would be cropped heavily or are too small are still flagged, and you decide.

5. A week of posts: /bulk-posts

To prepare several posts at once, copy briefs/TEMPLATE.md (for example to briefs/2026-11-02-week.md), write one ## Post block per post, and put each post's photos in a folder next to it. Then type /bulk-posts and give the file (or paste the brief).

  • Claude shows one plan for the whole batch: number, date, format, template and color, headline, photos and warnings, with a picture of each post. It varies layouts and colors across the week.
  • Change any post in plain words, then choose Build all.
  • Each post becomes its own run on the Generated page (run IDs end in -01, -02, …) and is checked like any other post. If one post fails, Claude marks it as failed, finishes the others, and tells you what went wrong.
  • The final message has a link, the warnings and a ready-to-copy caption for every post. A summary of the batch is saved in runs/batch-<batch ID>.json.

6. Adding images

When Claude reaches an image slot, you can provide the image in any of these ways:

MethodHow
Drag and dropDrag the file from Finder / Explorer into the Claude Code window. This inserts the file's path. Press Enter.
File pathType or paste the path, for example ~/Desktop/shoot/IMG_2041.jpg.
FolderGive a folder path. Claude lists its PNG/JPG/WebP images with their sizes (other files are skipped) and asks: Assign in order or Choose per slot.
URLA direct link to an image file (it must open as an image in the browser).
Already in FigmaThe name of an image already on the file's Media page.
SkipKeep the template placeholder image. This is listed as a warning on the summary card.

Story backgrounds. Some story designs (Share Opinion, What Do You Think, Photo Talk, Photo Poll) have a photo behind the whole story. Claude asks whether to keep the template photo or use your own. Keeping it is fine and is not a warning.

Black-and-white designs. Some layouts show photos in black and white on purpose, for example the Light and Dark versions of the carousel photo slides. Claude tells you before you pick the photo.

Use files, not clipboard pastes. A screenshot pasted straight from the clipboard is visible to Claude but is not saved as a file, so it cannot be uploaded to Figma. Save it as a file first, then drag that file in.

Image requirements

  • Formats: PNG, JPG or WebP. Maximum 10 MB per file.
  • Resolution: Claude tells you the ideal width for each photo slot (about 1080 px for a full-slide photo) and warns you if an image is smaller.
  • Orientation: Claude describes each slot (portrait, landscape, square). If more than about a quarter of the image would be cropped away, it warns you and lets you pick another one.
  • Uploaded images are stored on the Figma Media page as media/<run ID>/<file name>, so they can be reused later.

7. Reviewing and exporting

Check the result

Claude checks every slide before it reports success:

  • every field shows exactly what you typed, with no template placeholder text left;
  • no text is cut off or runs outside its box or card;
  • no template photo is left anywhere on the slide, including story backgrounds;
  • no text is so short that it leaves a visible gap in the design;
  • a screenshot of the whole run looks right.

If something cannot be fixed automatically, Claude names the slide and the field and offers options: shorten or extend the text, switch layout, or use a different image.

Open the link from Claude's final message. It takes you straight to your run's section on the Generated page.

Export for Instagram

  1. In Figma, select the slides of your run (not the summary card). Slides are named <run ID>_01, _02, ...
  2. Export settings are already applied. In the right panel, click Export.
  3. The files are numbered in slide order, ready to upload as a carousel.
FormatExported size
Feed post / carousel slide1080 px wide (about 1080 × 1354, 4:5), PNG
Story1080 px wide (about 1080 × 1922, 9:16), PNG

Copy the caption and hashtags from the summary card, or from Claude's final message.

8. Changing an existing post: /edit-run

To change a post that has already been generated, type:

/edit-run

Give the run ID (for example BG-20261023-1430-anna) or paste the Figma link to the run's section. Then tell Claude what to change:

  • a text on a specific slide;
  • a photo, including a story background;
  • the color of the whole run;
  • add, remove or reorder slides;
  • the caption or hashtags.

Claude shows you before → after and asks you to confirm. It then edits the run in place (the section stays where it is), checks it again, and adds a Revisions entry to the summary card: who changed what, and when. Slides that are rebuilt lose any manual edits made to them in Figma; Claude reminds you before applying.

Prefer /edit-run over editing by hand in Figma. Manual edits work, but they are not recorded on the summary card, and detaching instances breaks the link to the templates.

9. Templates and designers

Templates live on the Figma Templates page. Claude reads their names and layers every time, so a designer can add or update templates without touching the project folder.

  • At the start of every /new-post, Claude checks whether templates have changed and refreshes its template list automatically.
  • To refresh manually, for example right after a designer's change, type /sync-templates. Claude reports new templates and any naming problems.

Rules for designers

  • Name components Type / Layout / Color, for example Review / Hashtag / Light Pink.
  • Keep layer names meaningful. Claude fills layers named tagline, title, body, quote-text, author-name, author-handle, author-role, source-label, paragraph, bullet, button-label, photo, avatar and rating. Brand tags (tag-label) and page numbers (page-number) are filled automatically.
  • Name the italic highlighted part …-accent (title-accent, quote-text-accent), and number repeated fields (body-1, body-2, bullet-1). Two layers with the same name are still handled, but by position only.
  • Use the text's list formatting for bullets; Claude never types bullet characters.
  • Put decorative artwork inside layers named decor, bg, card-bg, mockup or photoshop, so Claude does not treat it as content. The list is in config.json (scan.decorContainers).
  • A photo fill on the component itself (a story background) becomes an optional background photo, unless it repeats the photo layer's own image, in which case it is replaced together with the photo.
  • Frames whose name contains (CLAUDE - IGNORE) are never read or changed.
  • /sync-templates reports naming problems and proposes renames. It changes the Templates page only after you confirm.

10. Using another Claude account or a team

Nothing in the project folder is tied to a person or an account. There are no personal tokens, IDs or paths in it. The same folder works for anyone.

Switching to another Claude account (for example a corporate one)

  1. Sign in to Claude Code with the new account. Terminal: /login. Desktop app: sign out, then sign in again.
  2. Open the same bride-groom-posts folder.
  3. Reconnect Figma if asked (setup, step 4).
  4. Run /new-post.
Company plans (Team / Enterprise): administrators can restrict which external servers Claude Code may use. If the figma server does not appear or is blocked, ask your Claude admin to allow the Figma server https://mcp.figma.com/mcp.

Sharing with the team

  • Keep the folder in a private Git repository (recommended) or share it as a zip.
  • Each person connects their own Figma account and needs edit access to the file.
  • Several people can generate posts at the same time. Each run gets its own section, placed below the previous ones.
  • Every run is also logged locally in runs/. You can commit these logs to share the history. /edit-run also works without them, by reading the run straight from Figma.

Using a copy of the Figma file

If the team works in a duplicate of the templates file, open config.json, replace fileKey with the key of the new file, then run /sync-templates. The key is the part of the file link after /design/. No other change is needed.

11. Troubleshooting

What you seeWhat to do
Claude says Figma is not connected, or the Figma tools are missingType /mcp → figma → Authenticate (terminal and desktop app), or connect the Figma connector in Settings → Connectors (desktop app). Then run /new-post again.
"The text is shorter than the design expects"The design leaves an empty gap under short text. Add a little more text (Claude says roughly how much), or keep the gap.
"Permission" or "seat" error when buildingYour Figma account cannot edit the file. Ask the owner for "can edit" access. Claude tells you which access is missing.
"Text does not fit"Shorten the text, or choose a layout with more room. Font sizes are never reduced, to keep the brand consistent.
Image rejectedCheck the format (PNG/JPG/WebP) and size (≤ 10 MB). Save clipboard screenshots as files first.
"Heavy crop" warningThe image orientation does not match the slot. Choose a better-matching photo, or accept the crop.
A color you want is not offered for a layoutThat layout does not exist in that color. Accept the suggested closest color, or pick another layout.
Two text fields of a layout always show the same textA template defect: both layers are bound to the same text property in Figma. /sync-templates reports it, Claude doesn't auto-pick such a layout, and it stops with a clear message if one is chosen. Pick another layout, or ask a designer to give the accent layer its own text property, then run /sync-templates.
Claude asks for permission before Figma stepsChoose Always allow once per tool. In cloud sessions, check that the session has only this one repository (the shared permission settings are read only then), or pick Auto mode if your organization allows it.
No pictures of the templates are shownThe previews are missing or out of date. Run /sync-templates. The questions still work without pictures.
A photo shows as a grey box in FigmaFigma could not read the file (this happens with some WebP images). Claude spots it in its screenshot check and asks for a PNG or JPG version.
A photo link does not download (cloud session)The cloud environment only reaches allowed websites. Upload the file instead, or ask the environment owner to allow that site (README → Cloud sessions).
Figma rate-limit messageWait a few minutes and repeat the last step. Your answers are kept.
Templates were just changed by a designerNothing to do: Claude refreshes automatically. You can also run /sync-templates.
